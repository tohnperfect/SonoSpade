# Data

Data and model checkpoints are **not** shipped in this repo (they are large and/or third-party).
Everything is regenerated by the scripts. `manifest.json` records the expected artifacts.

## 1. Real ultrasound (for the sim→real head-to-head and the reward judge)
**Kaggle "ussimandsegm" (Vitale et al.)**: real abdominal B-mode + organ masks.
Download from Kaggle (`ignaciorlando/ussimandsegm`), then ingest:

```bash
python scripts/ingest_kaggle_us.py --src ~/path/to/ussimandsegm --size 128 \
    --pool-dir data/real/kaggle_vitale/pool \
    --test-out data/eval/kaggle_vitale_test.npz
```

This writes the 404-frame unlabeled real **train** pool (translator target) and the 60-frame
labeled real **test** set (`liver, kidney, gallbladder, spleen, vessel`).

## 2. CT label volumes (the simulator content)
The physics renderer slices **TotalSegmentator v2** abdominal CT cases. Place each case as
`data/raw/totalseg_small/<case>/ct.nii.gz` + `.../segmentations/<structure>.nii.gz`. `usbg.volume`
builds and caches a canonical labeled volume to `data/cache/<case>.npz` (built once). Then render
aligned `(image, label)` pairs:

```bash
python scripts/make_dataset.py --cases s1086 s0777 --target liver \
    --n-per-case 200 --image-size 128 --out data/dataset/pairs_med.npz
```

## 3. What the experiments write (checkpoints in `data/dataset/`)
| file | produced by |
|---|---|
| `s_us*.pt` (frozen segmenter) | `train_segmenter.py` |
| `exp_real_sonospade.pt` (SonoSPADE) | `train_texture_gan.py --variant sonospade` |
| `exp_real_cut.pt`, `exp_real_cyclegan.pt` (baselines) | `train_texture_gan.py --variant cut|cyclegan` |
| `pairs_med.npz`, `pairs_med_curvi*.npz` | `make_dataset.py` / `curvi_warp.py` |
| `kaggle_vitale_test.npz` | `ingest_kaggle_us.py` |

The one-command drivers `scripts/run_sonospade_experiment.sh` and
`scripts/run_sonospade_experiment_real.sh` chain these end-to-end.

> **Fairness note:** for the sim→real head-to-head all translators must be trained on the *same*
> real pool (`exp_real_*.pt`, i.e. the Kaggle Vitale train split). Do **not** mix in a CUT checkpoint
> trained on a different real distribution, only the texture stage should differ across arms.
